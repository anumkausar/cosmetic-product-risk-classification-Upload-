# Cosmetic Product Safety Analysis Using Machine Learning

Put the INCIDB `archive` folder beside `main.py`.

Then run:
`py -m pip install -r requirements.txt`
`py main.py`

The project connects products with ingredients, creates ingredient-based product features, trains a Random Forest classifier, evaluates it, and creates charts.

Important: the risk labels are derived from dataset features for a machine-learning learning project. They are not medical safety diagnoses or guarantees.
