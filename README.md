# Cosmetic Ingredient Risk Classification

## Project Overview

This project is a Machine Learning based Cosmetic Ingredient Risk Classification system designed to analyze cosmetic product ingredients and classify products into different risk categories.

The main purpose of this project is to explore how machine learning can be used with cosmetic ingredient data to identify patterns and classify cosmetic products based on their associated ingredient risk levels.

The system uses ingredient information, product-ingredient relationships, and product data to prepare the dataset for machine learning and then predicts the risk category of a cosmetic product.

## Risk Categories

The model classifies cosmetic products into three categories:

* **Low Risk**
* **Moderate Risk**
* **Higher Risk**

These categories are used as classification labels for the machine learning model.

The project works with multiple datasets related to cosmetic products and their ingredients.
